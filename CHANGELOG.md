# Changelog

## 0.4.0 — initial GitHub lab distribution

- Portable PRM planning with configurable objectives, scene families and queries.
- UR5e and the fixed-open Robotiq/D435/PickNik assembly with bundled geometry.
- Independent sampled mesh verification, Pareto exploration, selection, export and CPU video previews.
- Static Isaac/USD import and editable, self-contained research scene examples.
- Two-wall XY enumeration with an automatic gallery of accepted environments.
- Seven archived environments, 21 preference-route videos and one smoothing comparison.
- New English/Hebrew onboarding, task recipes, capability map and developer guidance.
- Automated tests and documented clean-install/asset-portability checks.

The version identifies the toolkit release, not a rerun of the historical large
PRMs. See the example guides for each archived experiment's scope and hardware.
